## Why I'm building it

Healthcare is a domain where data errors have real consequences: a duplicated patient, a missing discharge date or a mismatched record changes what a report says about care. This project applies the validation discipline from my football work to a completely different sector.

## The data

Crestfield is a fictional hospital set in Kano State. Its database is large, realistic and deliberately messy, and every record is synthetic.

## What it will show

- SQL queries that find and classify data-quality problems across hospital records.
- Healthcare analysis built only on records that pass validation.
- Power BI dashboards that summarise both the analysis and the state of the data.
