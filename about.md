I’m Joshua Anayochukwu, a data professional from Nigeria. As a Data Validation Specialist at Sportmonks, a global sports data provider, I verify fixtures, teams, players, officials, several other football data that customers rely on before anyone builds an analysis on them. This work taught me something most dashboards hide: an insight is only as good as the data behind it. I care about what data says, even more about whether it is accurate. Checking before trusting has become a habit, and it runs through all of my work.

My work sits where four disciplines meet. Validation is my foundation: systematic checks, careful research, and the patience to chase down the one record that doesn’t add up. Analytics is where clean data becomes answers, and I use Excel, SQL and Power BI to find patterns and explain them plainly. Data engineering is the skill I’m actively building, learning through portfolio projects how pipelines and data warehouses keep data reliable as it moves and grows. AI automation, with tools like n8n and Supabase, lets me hand repetitive checks to machines so people can focus on judgement.

Together, these add up to one idea: data has to be trustworthy before it can be useful. I want to build systems that catch problems early, run without constant hand-holding, and give decision-makers numbers they don’t have to second-guess. {% if site.links.medium != "" %}[I also write]({{ site.links.medium }}){% else %}I also write{% endif %}, so I care about explaining technical work in simple everyday language. The projects below show where I am today. The direction is simple: get the data right, and everything built on it becomes better.
